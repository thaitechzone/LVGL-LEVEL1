## 1. เป้าหมายการเรียนรู้

เมื่อจบใบงานนี้ ผู้เรียนต้องทำได้ทุกข้อ

1. อธิบายวงจรของตัวควบคุม **อ่าน → ตัดสินใจ → สั่งงาน** และการแบ่งงานของโปรแกรมที่ไม่ใช้ `delay()`
2. ใช้ **hysteresis** กับพัดลม ไฟปลูก และปั๊ม พร้อมคำนวณเกณฑ์เปิด-ปิดด้วยมือ
3. คำนวณ duty ของพัดลมตามอุณหภูมิ และค่า PWM ที่เขียนจริง (active-LOW)
4. แปลงค่า raw ของ LDR เป็นเปอร์เซ็นต์แสงด้วย `map()` และ calibrate ช่วงมืด/สว่างให้ตรงห้อง
5. อธิบายความต่างของโหมด **AUTO / MANUAL** ลำดับความสำคัญ และเหตุผลที่ MANUAL ต้องไม่ข้ามกลไกความปลอดภัยของปั๊ม
6. อธิบายและคำนวณพฤติกรรมของ **ระบบป้อนกลับ** ปั๊ม–ความชื้นดิน (เวลาแห้ง เวลารด รอบการทำงาน)
7. อธิบายกลไกความปลอดภัย: **watchdog, cooldown, fail-safe, หยุดฉุกเฉิน** และออกแบบกลไกเพิ่มเองได้
8. ใช้เวลาจริงจาก NTP ทำ **ตารางเวลา** (ช่วงเปิดไฟ รอบรดน้ำ) และอธิบายเมื่อยังไม่มีเวลา ระบบควรทำอะไร
9. ดัดแปลงโปรแกรมตามโจทย์ (กฎเพิ่ม, ตัวนับ, ถ่วงเวลาขั้นต่ำ) และทดสอบด้วย Serial

## 2. ภาพรวมสิ่งที่จะสร้าง

```
 เซนเซอร์                      ตัวตัดสินใจ (ทุก 200 ms)              อุปกรณ์ (LED จำลอง)
 DHT11  อุณหภูมิ ──┐            ┌───────────────────────┐          ┌─ พัดลม  LED น้ำเงิน GPIO17 (PWM)
 DHT11  ความชื้น ──┤            │ updateFan   (hysteresis)│─────────►│
 LDR    แสง ───────┼──────────► │ updateLight (แสง+เวลา) │─────────►├─ ไฟปลูก LED เขียว GPIO16
 ดินชื้น (จำลอง) ──┤            │ updatePump  (เวลา+ดิน)  │─────────►└─ ปั๊มน้ำ LED แดง   GPIO4
 NTP    เวลาจริง ──┘            └──────────▲────────────┘
                                          │ AUTO / MANUAL, เกณฑ์ (SETUP), ปุ่ม BOOT = หยุดฉุกเฉิน
                                  จอสัมผัส (Lab 9)
```

| หน้าจอ | ใช้ทำอะไร |
|---|---|
| **DASH** | ดูภาพรวม: เวลา, TEMP / HUM / LIGHT / SOIL (พร้อมป้ายแหล่งที่มา), สถานะพัดลม ไฟ ปั๊ม |
| **CTRL** | สลับ AUTO/MANUAL และสั่ง ON/OFF ของแต่ละอุปกรณ์ |
| **SETUP** | ปรับเกณฑ์และตารางเวลา 2 หน้า (แตะแท็บ SETUP ซ้ำเพื่อสลับหน้า) |
| **SYSTEM** | ความสว่างจอ, ขอ NTP, ทดสอบจอสัมผัส, **ตั้งช่วงมืด/สว่างของ LDR**, calibrate จอสัมผัส |

## 3. ความรู้พื้นฐานที่ต้องเข้าใจก่อนลงมือ

### 3.1 วงจรควบคุม: อ่าน → ตัดสินใจ → สั่งงาน

`loop()` ทำงานเป็นรอบเร็วๆ โดยแต่ละงานมีตัวจับเวลาของตัวเอง (เหมือน Lab 2–9) :

| งาน | ความถี่ |
|---|---|
| อ่านจอสัมผัส | ทุก 10 ms |
| อ่าน LDR (เฉลี่ย 8 ครั้ง + ตัวกรอง EMA) | ทุก 100 ms |
| อ่าน DHT11 | ทุก 2.5 วินาที (ใช้เวลา ≈ 25 ms ต่อครั้ง) |
| คำนวณความชื้นดินจำลอง | ทุก 1 วินาที |
| ตัดสินใจและสั่ง 3 อุปกรณ์ (`updateControl`) | ทุก 200 ms |
| วาดจอเฉพาะส่วนที่เปลี่ยน | ไม่เกินทุก 100 ms |

อุปกรณ์แต่ละตัวมีโครงสร้างเดียวกัน:

```cpp
struct Device {
    Mode mode = Mode::Auto;   // AUTO = ทำตามกฎ , MANUAL = ทำตามผู้ใช้
    bool manualOn = false;    // สถานะที่ผู้ใช้สั่งเมื่ออยู่โหมด MANUAL
};
Device fanDev, lightDev, pumpDev;
```

### 3.2 hysteresis (ทบทวนจาก Lab 6 และขยายไปทุกอุปกรณ์)

ถ้าใช้เกณฑ์เดียว (เปิดเมื่อ ≥ 30 ปิดเมื่อ < 30) อุณหภูมิที่แกว่งรอบ 30 °C จะทำให้อุปกรณ์เปิด-ปิดถี่ ๆ จึงใช้ **สองเกณฑ์** ที่ห่างกัน

| อุปกรณ์ | เปิดเมื่อ | ปิดเมื่อ | ช่วงที่ "ไม่เปลี่ยนสถานะ" |
|---|---|---|---|
| พัดลม | อุณหภูมิ ≥ 30 °C | อุณหภูมิ ≤ 28 °C | 28 < T < 30 |
| ไฟปลูก | แสง < 40% (และในช่วงเวลา) | แสง ≥ 45% (หรือออกนอกช่วงเวลา) | 40 ≤ แสง < 45 |
| ปั๊ม (ตามดิน) | ดิน < 35% | ดิน ≥ 55% (35 + 20) | 35 ≤ ดิน < 55 |

ใน `updateFan()` การจำสถานะทำด้วยตัวแปร `fanAutoOn` ซึ่งเป็น "ความจำ" ของ hysteresis

### 3.3 AUTO / MANUAL และลำดับความสำคัญ

- **AUTO:** อุปกรณ์ทำตามกฎ
- **MANUAL:** อุปกรณ์ทำตามที่ผู้ใช้สั่ง (`manualOn`) พัดลม MANUAL ON = 100% (`MANUAL_FAN_PERCENT`)
- แตะปุ่ม `ON`/`OFF` ขณะอยู่ AUTO = สลับเป็น MANUAL ให้เอง
- เปลี่ยน AUTO → MANUAL จะ "คงสถานะปัจจุบัน" ไว้ก่อน (ไม่ให้อุปกรณ์กระตุก) ส่วน MANUAL → AUTO ให้กฎกลับมาตัดสินใจ
- **กลไกความปลอดภัยของปั๊มชนะทุกโหมด** (หัวข้อ 3.8) ผู้ใช้สั่ง MANUAL ON ก็ถูกบังคับดับที่ 30 วินาที
- ปุ่ม **BOOT** = หยุดฉุกเฉิน: ทุกอุปกรณ์เป็น MANUAL + OFF เมื่อเปิดเครื่องใหม่ทุกอย่างกลับเป็น AUTO (โหมดไม่ถูกจำ)

### 3.4 เซนเซอร์แสง LDR และการแปลงเป็นเปอร์เซ็นต์

จาก Lab 2: raw ของ LDR **แปรผกผันกับแสง** (มืด = raw สูง, สว่าง = raw ต่ำ) ใช้ `analogSetPinAttenuation(LDR_PIN, ADC_0db)` เพื่อขยายช่วงค่า แปลงด้วย

```cpp
const long pct = map(lroundf(ldrSmooth), ldrRawDark, ldrRawBright, 0, 100);  // มืดก่อน สว่างทีหลัง
return constrain(pct, 0L, 100L);
```

ตัวอย่าง (ช่วงเริ่มต้น มืด = 300, สว่าง = 0) : `เปอร์เซ็นต์ = (raw − 300) × 100 ÷ (0 − 300) = (300 − raw) ÷ 3` (หารจำนวนเต็ม)

| raw | คำนวณ | แสง |
|---|---|---|
| 270 | (300 − 270) ÷ 3 | 10 % |
| 180 | (300 − 180) ÷ 3 | 40 % (ขอบเกณฑ์เปิดไฟ) |
| 150 | 150 ÷ 3 | 50 % |
| 0 | 300 ÷ 3 | 100 % |
| 333 | (300 − 333) ÷ 3 = −11 → `constrain` | 0 % |

**ช่วงมืด/สว่างขึ้นกับห้องและเวลา:** บนบอร์ดต้นแบบตอนกลางคืน raw ≈ 270–340 เมื่อไม่ได้บังเซนเซอร์ และ ≈ 0 เมื่อส่องไฟหรือในที่สว่าง (ค่า 120 ที่ใช้ใน Lab 2 ใช้ไม่ได้ในคืนนั้น) จึงมีปุ่ม `LDR SET DARK` / `LDR SET BRIGHT` จำค่า raw ปัจจุบัน (เฉลี่ยแล้ว) เป็นปลายแต่ละด้าน ต้อง "มืด > สว่าง" และห่างกันอย่างน้อย 20 (`LDR_MIN_SPAN`)

### 3.5 พัดลม: ความเร็วตามอุณหภูมิ และค่า PWM (active-LOW)

เมื่อพัดลมเปิด ความเร็วเพิ่มตามอุณหภูมิ จาก `FAN_MIN_DUTY_PERCENT` = 30% ที่เกณฑ์เปิด ไปถึง 100% ที่ `FAN_FULL_TEMP_C` = 36 °C

```
duty = 30 + round( clamp((T − fanOn) ÷ (36 − fanOn), 0, 1) × 70 )
```

เมื่อ `fanOn` = 30 : span = 6

| อุณหภูมิ | fraction | duty |
|---|---|---|
| 30.0 | 0 | 30 % |
| 31.0 | 0.1667 | 30 + 11.67 → **42 %** |
| 33.0 | 0.5 | 30 + 35 = **65 %** |
| 36.0 ขึ้นไป | 1 | **100 %** |

ค่า PWM 8 บิตที่คำนวณคือ `value = (duty × 255 + 50) ÷ 100` แล้วเนื่องจาก LED เป็น active-LOW จึงเขียน `255 − value`: duty 42% → value 107 → เขียน 148 ; duty 65% → 166 → เขียน 89 ; duty 100% → 255 → เขียน 0

ถ้าเซนเซอร์อุณหภูมิเสียและไม่ได้ใช้ SIM (`isnan(tempC)` และ `sensorError`) จะเข้า **fail-safe** พัดลมหมุน 50% (`SENSOR_FAIL_FAN_PERCENT`) ป้ายบนจอเป็น `FAILSAFE` สีแดง

### 3.6 ไฟปลูก: แสง + ช่วงเวลา

ไฟปลูกเปิดเมื่อ **ทั้งสองข้อ** เป็นจริง: อยู่ในช่วงเวลา (เช่น 06:00 ≤ ชั่วโมง < 18:00) และแสง < เกณฑ์ (40%) ปิดเมื่อออกนอกช่วงเวลา หรือแสง ≥ เกณฑ์ + 5% (hysteresis)
**ถ้ายังไม่มีเวลาจริง** (`!timeValid()`) โปรแกรมไม่ใช้ช่วงเวลา (ถือว่าอยู่ในช่วง) ตัดสินใจจากแสงอย่างเดียว เพราะไม่ควรเดาเวลาเอง

### 3.7 ดินชื้นจำลอง และระบบป้อนกลับ

ไม่มีเซนเซอร์ดินจริง โปรแกรมจำลองความชื้นดิน ทุก 1 วินาที

- ปั๊มหยุด: `soil = soil − 0.2` (ดินแห้งลง)
- ปั๊มทำงาน: `soil = soil + 1.5` (ดินเปียกขึ้น)
- จำกัดในช่วง 0–100

(อัตราเหล่านี้เร็วกว่าของจริงมาก เพื่อให้เห็นผลภายในวินาที)

ตัวอย่างการคำนวณ ด้วยเกณฑ์แห้ง 35% เปิดที่ < 35 และหยุดที่ ≥ 55 :

| รายการ | คำนวณ | ผล |
|---|---|---|
| เวลาที่ดินแห้งจาก 55% ลง 35% | 20 ÷ 0.2 | 100 วินาที |
| เวลารดจาก 35% ถึง 55% | 20 ÷ 1.5 | ≈ 13.3 วินาที |
| รอบเต็ม (แห้ง + รด) | 100 + 13.3 | ≈ 113 วินาที |
| ปั๊มทำงานกี่ % ของเวลา | 13.3 ÷ 113.3 | ≈ 11.8 % |
| รดตามตาราง 10 วินาที ดินขึ้นเท่าไร | 10 × 1.5 | +15 % |

ผลที่วัดจากบอร์ดต้นแบบ: แตะ SOIL ให้ดินเหลือ 20% → ปั๊มเริ่ม → ดินขึ้นถึง 56% ใช้เวลา 23 วินาที (ตรงกับ 36 ÷ 1.5 = 24) → ปั๊มหยุด

### 3.8 ปั๊มน้ำ: เงื่อนไขเริ่ม และกลไกความปลอดภัย

**เงื่อนไขเริ่ม (AUTO) :**

1. **ตามตารางเวลา:** ถึงรอบรดน้ำ H โดยที่เวลาท้องถิ่น (นาทีของวัน) อยู่ในช่วง `[H×60, H×60 + 5)` และรอบนั้นยังไม่ได้ทำ "วันนี้" รดนาน `RUN TIME` (10 วินาที)
   ตัวอย่าง H = 7 : 420 ≤ นาทีของวัน < 425 (07:00–07:04) ; วันนี้คำนวณจาก `(เวลา epoch + 25,200) ÷ 86,400` (เวลาท้องถิ่น UTC+7 ตามที่เรียนจาก Lab 7)
2. **ตามดินแห้ง:** ดิน < `SOIL DRY` (35%) รดจนดิน ≥ 55% หรือครบเวลาสูงสุด

**กลไกความปลอดภัย (ใช้กับทั้ง AUTO และ MANUAL) :**

| กลไก | ค่า | ทำอะไร |
|---|---|---|
| watchdog | `PUMP_MAX_RUN_SEC` = 30 วินาที | ปั๊มทำงานต่อเนื่องเกินนี้ถูกบังคับดับ (ตรวจเป็นอันดับแรกใน `updatePump`) |
| cooldown | `PUMP_COOLDOWN_SEC` = 20 วินาที | หลังหยุดทุกครั้ง ห้ามเริ่มใหม่จนกว่าจะพักครบ (จอขึ้น `REST`, Serial `refused: resting for N more s`) |
| รอบรดตามตาราง | ครั้งเดียวต่อวันต่อรอบ | ช่วงผ่อนผัน 5 นาที เลยแล้วถือว่าพลาด (นับใน RAM: รีเซ็ตบอร์ดในช่วงผ่อนผันอาจรดซ้ำ) |
| หยุดฉุกเฉิน | ปุ่ม BOOT | ทุกอุปกรณ์ MANUAL + OFF |

### 3.9 fail-safe: ไม่ใช้ค่าปลอมแอบๆ

ใน Lab 6 เมื่อ DHT11 เสีย โปรแกรมสุ่มค่าจำลองให้เองเพื่อให้ระบบเดินต่อ แต่ตัวควบคุมจริงที่ตัดสินใจจากข้อมูลปลอมอันตรายกว่า Lab นี้จึงตั้ง `SIM_WHEN_NO_SENSOR = false`: เซนเซอร์เสียจะขึ้นป้าย `ERR` สีแดง ค่าเป็น `--` และพัดลมเข้าโหมด fail-safe (หมุน 50%) ผู้ใช้เลือกใช้ SIM เองได้ด้วยการแตะการ์ด TEMP / HUM

## 6. แบบฝึกหัด

ก่อนแก้ทุกข้อให้จดสภาพเดิมไว้เทียบ ทำทีละข้อ (แก้ → build/upload → ดูผล → ย้อนกลับ)

### ระดับ 1 — พื้นฐาน (ข้อละ 5 คะแนน)

**ข้อ 1 — คำนวณช่วงแสงของห้องคุณ:** จากค่า DARK/BRIGHT ที่ calibrate ในขั้นที่ 4 คำนวณ raw ที่ตรงกับ LIGHT 40% และ 45% ด้วยสูตร `map` จำนวนเต็ม แล้วตรวจกับหน้าจอ/Serial จริง (ใช้มือบังจนได้ค่าใกล้เกณฑ์) รายงานผลเทียบ

**ข้อ 2 — คำนวณและวัดระบบดินชื้น:** ทำนาย (ก) เวลาที่ดินแห้งจาก 55% ลงถึง 35% (ข) เวลารดจาก 35% ถึง 55% (ค) เวลารอบเต็ม แล้วเปิดค่าเวลาจาก Serial จับเวลาจริงหนึ่งรอบ (ให้ดินเริ่มที่ 55% แล้วรอ — หรือแตะ SOIL แล้วดูแค่ช่วงรด) เทียบผล

**ข้อ 3 — ทดลองเปลี่ยนค่าคงที่:** ตั้ง `PUMP_MAX_RUN_SEC = 15` และ `SOIL_WET_RATE = 0.5f` ใน `app_config.h` ทำนายก่อนว่าแตะ SOIL แล้วจะเกิดอะไร (ปั๊มหยุดเพราะอะไร ดินขึ้นเท่าไร รอบถัดไปเป็นอย่างไร) แล้ว upload ดูเทียบ

### ระดับ 2 — ทดลองเข้าใจหลักการ (ข้อละ 7 คะแนน)

**ข้อ 4 — ระยะเวลาขั้นต่ำของไฟปลูก:** ตอนแสงแกว่งรอบเกณฑ์ ไฟอาจติด-ดับถี่ แม้มี hysteresis เพิ่มเงื่อนไข "ไฟต้องคงสถานะอย่างน้อย 5 วินาที" ในโหมด AUTO (โหมด MANUAL ไม่ติดเงื่อนไขนี้) ทดสอบด้วยการใช้แสงจำลอง/โบกมือ และอธิบายข้อดีข้อเสีย

**ข้อ 5 — พัดลมเพิ่มกฎความชื้น:** เมื่อความชื้นอากาศ ≥ 85% ให้พัดลมหมุนที่ `FAN_MIN_DUTY_PERCENT` แม้อุณหภูมิต่ำกว่าเกณฑ์ และหยุดเมื่อความชื้น ≤ 80% (hysteresis) ทดสอบด้วย SIM sweep (ความชื้นสวนทางกับอุณหภูมิ) และรายงานที่อุณหภูมิ/ความชื้นที่พัดลมเริ่มและหยุด

**ข้อ 6 — นับจำนวนรอบที่ปั๊มทำงานต่อวัน:** เพิ่มตัวนับที่รีเซ็ตเมื่อขึ้นวันใหม่ (ตามเวลาท้องถิ่น ระวังเรื่องวัน ตามที่เรียนจาก Lab 7) พิมพ์ใน Serial ทุกครั้งที่ปั๊มเริ่ม ทดสอบด้วยการสั่ง `p` หลายครั้ง (สลับ ON/OFF) และอธิบายว่ากรณีไม่มีเวลาจริงตัวนับควรทำอะไร

### ระดับ 3 — ออกแบบเอง (ข้อละ 10 คะแนน)

**ข้อ 7 — ตรวจจับปั๊มผิดปกติ (FAULT):** ถ้า watchdog ดับปั๊มติดกัน 2 ครั้งโดยดินยังไม่สูงถึง `SOIL DRY + 10` (แปลว่าไม่มีน้ำ หรือเซนเซอร์/ปั๊มผิดปกติ) ให้ล็อกปั๊มโหมด AUTO ไม่ให้เริ่มอีก แสดง `FAULT` สีแดงบนจอ (DASH และ CTRL) และ Serial และปลดล็อกได้ด้วยการกดปุ่ม BOOT หรือสั่ง `a` อธิบายเหตุผลของค่าที่เลือก และทดสอบด้วยการตั้ง `SOIL_WET_RATE` ต่ำมาก (เหมือนไม่มีน้ำ)

**ข้อ 8 (โบนัส +10) — ท้าทาย:** ใช้เซนเซอร์ความชื้นดินจริง (แบบ analog) แทนค่าจำลอง ตรวจ pinout ของบอร์ดก่อนเลือกขา (ขา input-only GPIO34/35/36/39 อ่านได้อย่างเดียว) เขียนวิธี calibrate แห้ง/เปียกคล้าย LDR และบอกผลที่สังเกต
