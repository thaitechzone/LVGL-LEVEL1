# Level 1 / Lab 10 — Smart Farm Controller: ตัวควบคุมโรงเรือนจำลอง

Lab นี้รวมสิ่งที่เรียนมาทั้งหมด (LDR, PWM, DHT11, WiFi/NTP, จอสัมผัส) เป็นระบบควบคุมโรงเรือนจำลอง: อ่านอุณหภูมิ ความชื้น แสง และความชื้นดิน
แล้วตัดสินใจสั่ง **พัดลม ไฟปลูก และปั๊มน้ำ** (ใช้ LED บนบอร์ดแทนอุปกรณ์จริง) ปรับเกณฑ์และตารางเวลาได้จากหน้าจอสัมผัส

> **สถานะการตรวจสอบ (อ่านก่อน):** โปรแกรม build ผ่านไม่มี warning และอัปโหลดลงบอร์ดจริงแล้ว ผมตรวจพฤติกรรมการควบคุมจาก Serial บนบอร์ดจริงหลายข้อ (ดูตาราง) ส่วนหน้าจอ
> ผู้พัฒนาแจ้งว่า "ผลถูกต้อง" ตามรายการที่ผมขอให้ทดสอบ **แต่ไม่ได้ส่งภาพถ่ายหน้าจอ** ผมจึงไม่ได้ตรวจเลย์เอาต์จากภาพ และจาก Serial ไม่เห็นเหตุการณ์ปรับเกณฑ์ในหน้า SETUP หรือกดปุ่ม `LDR SET DARK / SET BRIGHT`
> (หลังรีเซ็ตค่ายังเป็นค่าเริ่มต้นทั้งหมด) จึง **ยังไม่ยืนยัน** สองส่วนนี้ ดูตาราง "สถานะการตรวจสอบ" ท้ายไฟล์ ภาพ ASCII วาดประกอบ ไม่ใช่ภาพจริง
> **อุปกรณ์เป็นแค่ LED:** ไม่ได้ต่อพัดลม หลอดไฟ หรือปั๊มจริง (ห้ามต่อรีเลย์/โหลดไฟบ้านเข้าขาของบอร์ดโดยตรง) และ **ความชื้นดินเป็นค่าจำลองในโปรแกรม** ไม่ใช่เซนเซอร์จริง

## สิ่งที่จะได้เรียน

1. **ออกแบบตัวควบคุมหลายอุปกรณ์** ที่ทำงานพร้อมกันโดยไม่ใช้ `delay()` (แต่ละอุปกรณ์ตรวจเงื่อนไขทุก 200 ms)
2. **hysteresis** กับอุปกรณ์ทุกตัว (พัดลมตามอุณหภูมิ, ไฟปลูกตามแสง, ปั๊มตามความชื้นดิน) เพื่อไม่ให้เปิด-ปิดถี่
3. **โหมด AUTO / MANUAL** และลำดับความสำคัญ: ผู้ใช้สั่งเองได้ แต่ปั๊มยังถูกจำกัดด้วยความปลอดภัย
4. **ความปลอดภัยของอุปกรณ์** : ตัวจับเวลาสูงสุด (watchdog) ปั๊มทำงานต่อเนื่องได้ไม่เกิน 30 วินาที, ช่วงพักปั๊ม (cooldown) 20 วินาที, ปุ่มหยุดฉุกเฉิน
5. **fail-safe:** เมื่อเซนเซอร์เสีย ไม่ใช้ค่าปลอมแอบๆ แต่แสดง `ERR` และให้พัดลมเข้าโหมดปลอดภัย (หมุน 50%) แทนการหยุดเฉยๆ ; เมื่อยังไม่มีเวลาจริง ตารางเวลาจะถูกข้าม
6. **ตารางเวลา (schedule)** จากเวลาจริง NTP: ช่วงเวลาเปิดไฟปลูก และรอบรดน้ำ 2 รอบต่อวัน (รอบละหนึ่งครั้งต่อวัน มีช่วงผ่อนผัน 5 นาที)
7. **ระบบป้อนกลับ (feedback loop):** ดินแห้ง → ปั๊มทำงาน → ดินชื้นขึ้น → ปั๊มหยุด (ดินจำลองในโปรแกรม)
8. **เก็บค่าตั้งถาวร** (`Preferences`) และ **calibrate เซนเซอร์แสง** ให้ตรงกับห้องของเรา
9. **UI หลายหน้า** สำหรับแผงควบคุม (ภาพรวม / สั่งงาน / ตั้งค่า / ระบบ) ต่อยอดจากจอสัมผัส Lab 9

## ฮาร์ดแวร์และขา

| อุปกรณ์ | ขา | หมายเหตุ |
|---|---|---|
| พัดลมจำลอง = LED **น้ำเงิน** | GPIO17 | PWM (LEDC ช่อง 0) active-LOW |
| ไฟปลูกจำลอง = LED **เขียว** | GPIO16 | เปิด/ปิด active-LOW |
| ปั๊มน้ำจำลอง = LED **แดง** | GPIO4 | เปิด/ปิด active-LOW |
| DHT11 DATA | GPIO27 | ห้ามใช้ GPIO21 (ไฟหลังจอ) |
| LDR (เซนเซอร์แสงบนบอร์ด) | GPIO34 | ADC input-only ตั้ง attenuation 0 dB เหมือน Lab 2 |
| จอสัมผัส XPT2046 | GPIO25 / 39 / 32 / 33 | SPI ชุด VSPI เหมือน Lab 9 |
| ไฟหลังจอ (PWM) | GPIO21 | ปรับได้จากหน้า SYSTEM |

- **ย้ายสถานะ LED ไปบนจอ:** Lab 6–9 ใช้ LED แดง = เซนเซอร์มีปัญหา, เขียว = sync เวลาแล้ว Lab นี้ต้องใช้ LED ทั้งสามเป็นอุปกรณ์ จึงย้ายสถานะไปแสดงบนจอ: ป้าย `SYNCED` / `NO SYNC` / `NO WIFI` ที่การ์ดนาฬิกา และป้าย `ERR` สีแดงที่การ์ด TEMP / HUM
- จอสัมผัสใช้ VSPI ชุดเดียวกับ SD card (Lab 8) จึง **ยังไม่รวม SD card**
- ต้อง **calibrate จอสัมผัสใหม่** ในครั้งแรกของ Lab นี้ (เก็บค่าแยกจาก Lab 9) : แตะกลางกากบาทเขียว 4 จุด
- ไม่มี WiFi/`secrets.h` ก็ใช้ได้ แต่ไม่มีเวลาจริง ตารางเวลาจะถูกข้าม (ไฟปลูกใช้แสงอย่างเดียว ปั๊มใช้ดินแห้งอย่างเดียว)

## กติกาการควบคุม (โหมด AUTO)

| อุปกรณ์ | เปิดเมื่อ | ปิดเมื่อ |
|---|---|---|
| **พัดลม** | อุณหภูมิ ≥ `FAN ON` (ค่าเริ่มต้น 30 °C) ความเร็วเริ่ม 30% แล้วเพิ่มตามอุณหภูมิถึง 100% ที่ 36 °C | อุณหภูมิ ≤ `FAN OFF` (28 °C) |
| **ไฟปลูก** | อยู่ในช่วงเวลา `LIGHT FROM`–`LIGHT TO` (06:00–18:00) **และ** แสง < `LIGHT <` (40%) | ออกนอกช่วงเวลา หรือแสง ≥ 40% + 5% (hysteresis) |
| **ปั๊มน้ำ** | (ก) ถึงเวลารดน้ำ `WATER 1` / `WATER 2` (07:00, 17:00 เวลา HH:00 ถึง HH:05) นาน `RUN TIME` (10 วินาที) หรือ (ข) ความชื้นดิน < `SOIL DRY` (35%) | (ก) ครบเวลารด (ข) ความชื้นดิน ≥ ค่าแห้ง + 20% (55%) |

กฎความปลอดภัยของปั๊ม (ใช้กับทั้ง AUTO และ MANUAL):

- ทำงานต่อเนื่องได้ **ไม่เกิน 30 วินาที** (`PUMP_MAX_RUN_SEC`) หลังจากนั้นถูกบังคับดับ (watchdog)
- หลังหยุดทุกครั้ง **พัก 20 วินาที** (`PUMP_COOLDOWN_SEC`) ช่วงพักสั่งเริ่มไม่ได้ (จะขึ้น `REST` และ Serial แจ้ง `refused`)
- รอบรดน้ำตามเวลาทำได้ครั้งเดียวต่อวันต่อรอบ ถ้าเลยช่วงผ่อนผัน 5 นาทีก็ถือว่าพลาดรอบนั้น (ข้อสังเกต: นับในหน่วยความจำ ถ้ารีเซ็ตบอร์ดภายในช่วงผ่อนผันจะรดซ้ำ)

เมื่อเปิดเครื่อง ทุกอุปกรณ์เป็น **AUTO** เสมอ (ไม่จำโหมด MANUAL ข้ามการรีเซ็ต เพื่อความปลอดภัย)

### แท็บ DASH (ภาพรวม)

```
┌──────────────────────────────────────┐
│ Lab 10 - Smart Farm  ●    22:02:20   │
│ ┌──────────────────────────────────┐ │
│ │ 22:02:20      SYNCED    09/10/26 │ │ ← แตะ = ขอ NTP ใหม่
│ └──────────────────────────────────┘ │
│ ┌──────┐┌──────┐┌──────┐┌──────┐    │
│ │TEMP  ││HUM   ││LIGHT ││SOIL  │    │ ← แตะ TEMP/HUM = REAL/SIM
│ │27.4  ││94    ││0     ││59    │    │   แตะ LIGHT = LDR/SIM
│ │C REAL││% REAL││% LDR ││% SIM │    │   แตะ SOIL = ทำให้ดินแห้ง (ทดสอบ)
│ └──────┘└──────┘└──────┘└──────┘    │
│ ┌──────┐┌──────┐┌──────┐            │
│ │FAN   ││LIGHT ││PUMP  │            │ ← แตะ = ไปหน้า CTRL
│ │OFF   ││OFF   ││OFF   │            │
│ │AUTO  ││AUTO  ││AUTO  │            │
│ └──────┘└──────┘└──────┘            │
│ [DASH] [CTRL] [SETUP] [SYSTEM]       │
└──────────────────────────────────────┘
```

สีของตัวเลข: อุณหภูมิเป็นสีส้มเมื่อถึงเกณฑ์เปิดพัดลม, แสงเป็นสีเหลืองเมื่อต่ำกว่าเกณฑ์เปิดไฟ, ความชื้นดินเป็นสีแดงเมื่อแห้งกว่าเกณฑ์ ป้ายเล็กใต้ค่าบอกแหล่งที่มา: `REAL` (เซนเซอร์จริง), `SIM` (จำลอง), `LDR`, `ERR` (เซนเซอร์เสีย) , `N/A`

### แท็บ CTRL (สั่งงาน)

แต่ละอุปกรณ์มี 1 แถว: ชื่อ + สถานะ (เช่น `ON 45%`, `RUN 7s`, `REST 12s`, `FAILSAFE`) ปุ่ม `AUTO`/`MANUAL` และปุ่ม `ON`/`OFF`

| ปุ่ม | แตะแล้วทำอะไร |
|---|---|
| `AUTO` / `MANUAL` | สลับโหมด (AUTO → MANUAL คงสถานะปัจจุบันไว้ก่อน) |
| `ON` / `OFF` | แสดงสถานะจริง แตะเพื่อสลับ **และเปลี่ยนเป็น MANUAL ให้เอง** (ข้อความหรี่เมื่ออยู่ AUTO = อุปกรณ์ทำตามกติกา) พัดลม MANUAL ON = 100% |

### แท็บ SETUP (ปรับเกณฑ์ 2 หน้า)

แตะแท็บ `SETUP` ซ้ำเพื่อสลับหน้า 1/2 ปุ่ม `-` `+` เปลี่ยนทีละ 1 ขั้น (เปอร์เซ็นต์และวินาทีทีละ 5) **กดค้างเพื่อเพิ่ม/ลดต่อเนื่อง** และบันทึกลง flash ตอนปล่อยนิ้ว

| หน้า | แถว | ช่วงที่ปรับได้ |
|---|---|---|
| 1 | `FAN ON >=` / `FAN OFF <=` | 16–35 °C / 15–34 °C (ปิดต้องต่ำกว่าเปิดอย่างน้อย 1) |
| 1 | `LIGHT <` (เกณฑ์แสง) | 5–95 % |
| 1 | `LIGHT FROM` / `LIGHT TO` | 0–23 / 1–24 น. (TO ต้องมากกว่า FROM) |
| 2 | `SOIL DRY <` | 10–75 % (หยุดรดที่ค่านี้ + 20%) |
| 2 | `WATER 1` / `WATER 2` | 00:00–23:00 |
| 2 | `RUN TIME` | 5–30 วินาที |

### แท็บ SYSTEM

| ปุ่ม/ส่วน | แตะแล้วทำอะไร |
|---|---|
| แถบเลื่อน `BACKLIGHT` | ลากปรับความสว่างจอ 10–100% แล้วจำค่า |
| `SYNC NTP` / `TOUCH TEST` | ขอเวลาใหม่ / หน้าทดสอบจอสัมผัส (เหมือน Lab 9) |
| `LDR SET DARK` | **ครอบมือบังเซนเซอร์ LDR** (มุมขวาบนของจอ) แล้วกด = จำค่าตอนมืดสุด |
| `LDR SET BRIGHT` | **ที่สว่างปกติหรือส่องไฟ** แล้วกด = จำค่าตอนสว่างสุด (ต้องมีค่าห่างจากฝั่งมืดอย่างน้อย 20 ไม่งั้นปฏิเสธ) |
| `RECALIBRATE (hold 1 s)` | กดค้าง 1 วินาทีเพื่อ calibrate จอสัมผัสใหม่ |
| บรรทัดเล็กล่างสุด | `LDR <raw> [มืด..สว่าง]` (ค่าดิบและช่วงที่จำไว้) และสถานะ WiFi |

### ปุ่ม BOOT และคำสั่ง Serial

| คำสั่ง | ทำอะไร |
|---|---|
| ปุ่ม **BOOT** บนบอร์ด | **หยุดฉุกเฉิน**: ทุกอุปกรณ์เป็น MANUAL + OFF |
| `f` / `l` / `p` | สลับ ON/OFF แบบ MANUAL ของพัดลม / ไฟปลูก / ปั๊ม |
| `a` | ทุกอุปกรณ์กลับเป็น AUTO |
| `s` / `e` | สลับ REAL→SIM random→SIM sweep ของอุณหภูมิ+ความชื้น / สลับแสงจริง-จำลอง |
| `d` | ทำให้ดินแห้ง (ทดสอบปั๊ม) |
| `n` `t` `c` `k` `h` | ขอ NTP / พิมพ์เวลา / calibrate จอสัมผัส / พิมพ์ค่า calibrate+LDR / ช่วยเหลือ |

## ความรู้ใหม่ใน Lab นี้

### เซนเซอร์แสง LDR และการ calibrate

raw ของ LDR **แปรผกผันกับแสง** (มืด = raw สูง) และช่วงค่าแคบ (ตั้ง ADC 0 dB เหมือน Lab 2) แปลงเป็นเปอร์เซ็นต์ด้วย `map(raw, มืด, สว่าง, 0, 100)` แล้ว `constrain`
**ช่วงมืด/สว่างขึ้นกับห้อง:** บนบอร์ดต้นแบบตอนกลางคืน raw ≈ 270–340 และเมื่อมีแสงหรือถูกบัง/ส่องไฟ ≈ 0 ซึ่งต่างจากค่า 120 ที่ใช้ใน Lab 2 โปรแกรมจึงตั้งค่าเริ่มต้นมืด = 300, สว่าง = 0 และมีปุ่มจำช่วงใหม่ในหน้า SYSTEM
ค่าเหล่านี้เป็นของบอร์ดต้นแบบตัวเดียวในคืนที่ทดสอบ ของคุณจะต่างออกไป

### hysteresis ของไฟปลูก

เปิดเมื่อแสง < 40% ปิดเมื่อแสง ≥ 45% ระยะห่าง 5% กันไฟกะพริบเมื่อแสงอยู่ใกล้เกณฑ์ แต่ถ้าแสงแกว่งแรงข้ามช่วงทั้งหมด (เช่น โบกมือบังเซนเซอร์เร็วๆ) ไฟยังติด-ดับตามได้ (พบตอนทดสอบ) ซึ่งเป็นข้อจำกัดของ hysteresis แบบง่าย การแก้ที่ใช้กันจริงคือกำหนด "เวลาขั้นต่ำที่ต้องเปิด/ปิด" (เป็นแบบฝึกหัดได้)

### ระบบป้อนกลับของปั๊มกับดินชื้น (จำลอง)

ทุก 1 วินาที `soil = soil − 0.2` (ดินแห้งลง) หรือ `soil = soil + 1.5` (ขณะปั๊มทำงาน) ตัวเลขนี้เร็วกว่าของจริงมาก เพื่อให้เห็นผลภายในไม่กี่วินาที
ผลที่วัดจากบอร์ดต้นแบบ: ดินลงมาที่ 20% → ปั๊มเริ่ม (reason `SOIL DRY`) → ดินขึ้นถึง 56% ใช้เวลา 23 วินาที → ปั๊มหยุด (`soil wet enough`) → พัก 20 วินาที

### ความปลอดภัย: watchdog, cooldown, fail-safe

| กลไก | เหตุผล |
|---|---|
| ปั๊มทำงานต่อเนื่องไม่เกิน 30 วินาที (ทุกกรณี) | ถ้าโปรแกรมหรือเซนเซอร์ผิดพลาด ปั๊มไม่เดินจนน้ำล้น/มอเตอร์ไหม้ |
| พักปั๊ม 20 วินาทีหลังหยุด | ป้องกันเปิดปิดถี่เกิน |
| ไม่ใช้ค่าอุณหภูมิปลอมเมื่อเซนเซอร์เสีย (`SIM_WHEN_NO_SENSOR = false`) | ตัวควบคุมจริงไม่ควรตัดสินใจจากข้อมูลปลอม ; พัดลมเข้า fail-safe หมุน 50% แทนการหยุด |
| ไม่มีเวลาจริง = ข้ามช่วงเวลา/ตารางรดน้ำ | ไม่เดาเวลาเอง |
| ทุกอุปกรณ์เริ่มเป็น AUTO ทุกครั้งที่เปิดเครื่อง | MANUAL ไม่ติดค้างข้ามการรีเซ็ต |
| ปุ่ม BOOT = หยุดฉุกเฉิน | มีทางหยุดทุกอย่างได้เสมอ |

## วิธีทดสอบเร็วๆ

1. อัปโหลดแล้ว calibrate จอสัมผัส (ครั้งแรก)
2. **ปั๊มตามดินแห้ง:** แตะการ์ด SOIL บน DASH ดินจะเหลือ 20% → LED แดงติด ตัวเลข SOIL ขึ้นจนถึง 55% แล้วดับ แล้วขึ้น `REST` สักครู่
3. **พัดลม:** แตะการ์ด TEMP สองครั้ง (REAL → SIM random → SIM sweep) อุณหภูมิไล่ขึ้น-ลงทุก 60 วินาที LED น้ำเงินสว่างขึ้นตั้งแต่ 30 °C และดับที่ 28 °C
4. **ไฟปลูก:** ครอบมือบังเซนเซอร์ LDR ถ้าแสงต่ำกว่า 40% และอยู่ในช่วง 06:00–18:00 LED เขียวติด (นอกช่วงเวลาไม่ติด) หรือแตะการ์ด LIGHT เพื่อใช้แสงจำลอง
5. **MANUAL:** ไปแท็บ CTRL แตะ `ON` ของปั๊ม (ปั๊มติด ดับเองเมื่อครบ 30 วินาที) แล้วกด BOOT ดูว่าทุกอย่างดับ
6. **ตั้งค่า:** ไปแท็บ SETUP ลองเปลี่ยนเกณฑ์ แล้วรีเซ็ตบอร์ดดูว่าค่ายังอยู่
7. **รดน้ำตามเวลา:** ตั้ง `WATER 1` เป็นชั่วโมงปัจจุบัน ภายใน 5 นาทีแรกของชั่วโมงนั้น (HH:00–HH:04) ปั๊มจะเริ่มเองเมื่อได้เวลาจริงจาก NTP

ใบงานฉบับละเอียด: [WORKSHEET.md](WORKSHEET.md) (นักเรียน) และ [WORKSHEET_ANSWERS.md](WORKSHEET_ANSWERS.md) (เฉลยสำหรับผู้สอน)
